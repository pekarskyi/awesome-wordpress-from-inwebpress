# Основні загрози для WordPress

WordPress є найпопулярнішою системою керування вмістом (CMS) у світі, що робить її привабливою ціллю для зловмисників. Ось основні загрози для WordPress-сайтів:

## Вразливості програмного забезпечення

- **Застарілі версії ядра WordPress** — невстановлені оновлення безпеки залишають відомі вразливості
- **Вразливі плагіни та теми** — часто стають вхідними точками для атак через поганий код або відсутність оновлень
- **SQL-ін'єкції** — дозволяють зловмисникам маніпулювати базою даних через незахищені запити

## Проблеми з автентифікацією

- **Слабкі облікові дані** — прості паролі легко підбираються методом перебору (brute force)
- **Атаки на форму входу** — автоматизовані спроби вгадати логін/пароль
- **Викрадення сесій** — перехоплення сесій авторизованих користувачів

## Шкідливий код

- **Малвер** — шкідливий код, вбудований у теми, плагіни або завантажені файли
- **Бекдори** — приховані входи для доступу до сайту в обхід звичайної автентифікації
- **Фішинг** — підробні сторінки входу для крадіжки облікових даних

## Інші значні загрози

- **XSS (Cross-Site Scripting)** — впровадження шкідливих скриптів у веб-сторінки
- **CSRF (Cross-Site Request Forgery)** — примушування користувача виконати небажані дії
- **DDoS-атаки** — перевантаження серверу запитами для припинення роботи сайту
- **Спам у коментарях** — автоматизоване розміщення небажаного контенту
- **Файлові атаки** — завантаження шкідливих файлів через незахищені форми

Для захисту WordPress-сайту необхідно регулярно оновлювати ядро, плагіни і теми, використовувати надійну автентифікацію, встановлювати плагіни безпеки та налаштовувати резервне копіювання.
